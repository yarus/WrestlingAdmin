# WrestlingAdmin
Wrestling tournament administrator/director tool

It allows to run freestyle wrestling tournaments.

The following features are supported:
- Teams and Wrestlers registration tracking (register teams and wrestlers, provide weight information, select correct weight and age groups)
- Bracket generation depending on number of participants in each group (<6 - RoundRobbin, 6-7 - Split into 2 groups with round robin and best 4 goes to finals, 8+ - olympic with reconciliation)
- Match planning depending on number of carpets (mats)
- Tournament schedule - list of upcoming matches for each carpets
- Carpet management - run matches, deal with timers and carpet monitor with points, names, teams shown; provide match results
- Tournament Results calculation depending on group bracket type
- Supporting screen with upcoming matches, current brackets and option to show marketing images and videos
- Synchronize results between carpets using shared folders (computer on each carpet has to be in the same network as other computers to synchronize)
- Print reports (Brackets, Schedules, Results)

Currently tool only support Russian language but can be easily extended to support other languages.
